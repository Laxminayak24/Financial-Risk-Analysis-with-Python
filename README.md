# 💰 Financial Risk Analysis with Python

## 📌 Project Overview

This project focuses on analyzing financial account data using Python to identify risk patterns, detect anomalies, and understand inactive or dormant accounts.

The project demonstrates a complete data analysis workflow including data preparation, exploratory analysis, anomaly detection, and interpretation of financial risk indicators.

The objective is to transform raw financial data into meaningful insights that can support risk monitoring and data-driven decision-making.

---

## 🎯 Business Objective

The main objectives of this project are:

* Analyze financial account characteristics
* Identify inactive and dormant accounts
* Detect unusual or potentially risky observations
* Perform data cleaning and preparation
* Explore relationships between financial variables
* Identify patterns in customer/account activity
* Support financial risk monitoring using data analysis

This finding highlights the importance of monitoring account activity and investigating patterns associated with inactivity.
